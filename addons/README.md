# Дополнения сообщества

По папке на игру: `addons/<id>/addon.json`, где `<id>` совпадает с `id` в манифесте. Это копия каталога дополнений
сообщества в приложении ConnectTogether: папки пишет и удаляет зеркало каталога ([`scripts/mirror.py`](../scripts/mirror.py)),
правки руками и pull request сюда пропадут при следующем обновлении.

Как установить дополнение и как опубликовать своё — в [README](../README.md) и [CONTRIBUTING](../CONTRIBUTING.md).
