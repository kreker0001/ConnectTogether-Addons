# Формат addon.json

Дополнение — один файл `addon.json`. Всё, что касается игры, описывается в нём, а выполняет его приложение
ConnectTogether. Сеть остаётся за ConnectTogether: порты сервера с `expose: true` сами попадают в комнату, и друзья
заходят по адресу из неё — роутер настраивать не нужно.

Дополнение бывает двух видов:

- **ставит и запускает сервер** — есть `launch`. Приложение скачивает сервер из официального источника, запускает его,
  ждёт готовности и даёт консоль. У хоста есть кнопка «Запустить мой сервер»: сервер стартует, и сразу открывается
  комната. Примеры: [Minecraft](../examples/minecraft/addon.json), [Rust](../examples/rust/addon.json);
- **сервер с инструкцией** — без `launch`. Сервер запускает хост сам, а дополнение даёт порты для комнаты, шаги для
  хоста и подсказку друзьям, куда ввести адрес. Примеры: [Factorio](../examples/factorio/addon.json),
  [Valheim](../examples/valheim/addon.json), [Palworld](../examples/palworld/addon.json).

## Что видит пользователь

- **Настройки → Игры → «Добавить из файла».** Приложение проверяет файл и показывает все ошибки сразу. Если ошибок
  нет — что дополнение будет делать: что скачает и откуда, что запустит, какие порты откроет друзьям, сколько нужно
  памяти и места, какая у сервера лицензия. Только после «Добавить» игра появляется в списке и в «Создать комнату».
  Новая версия дополнения с тем же `id` заменяет прежнюю.
- **Создать комнату → игра.** Если сервер уже запущен на этом компьютере, приложение находит его по портам и открывает
  комнату. Если нет — показывает шаги из `guide.startSteps`, а у дополнения с `launch` — ещё «Запустить мой сервер».
- **Экран дополнения** (Настройки → Игры → «Сервер», а в открытой комнате — «Консоль сервера»): установка с
  прогрессом, предупреждение, если не хватает памяти или места, лицензия с кнопкой «Принимаю», настройки и порты,
  запуск, остановка, перезапуск, лог и поле для команд консоли.
- **Выход из приложения** при работающем сервере: приложение спрашивает, остановить ли его.

## Где что лежит на компьютере

```
%LOCALAPPDATA%\ConnectTogether\addons\
  <id>\addon.json       манифест
  <id>\server\          файлы сервера — это {dir}
  <id>\instance.json    настройки, порты и пароли этого сервера
  <id>\installed.json   какие шаги установки уже сделаны
  shared\               общие зависимости (Java) и SteamCMD
  tmp\                  временная папка процессов серверов
```

## Поля

| Поле | Что это |
|---|---|
| `$schema` | Ссылка на [схему](../schema/addon.schema.json): по ней редактор подсказывает поля. Приложение её не читает. |
| `format` | Версия формата, сейчас `1`. Другую приложение не откроет. |
| `id` | Имя папки: латиница в нижнем регистре, цифры, дефис, до 40 символов. |
| `name`, `subtitle`, `icon`, `version`, `author` | Как дополнение выглядит в приложении. `icon` — из набора приложения: `cube`, `axe`, `gamepad`, `server`, `puzzle`… |
| `requirements` | `ramGb`, `diskGb` — сколько памяти и места нужно серверу. Если на компьютере меньше, экран дополнения предупредит. |
| `install[]` | Что скачать, по порядку (ниже). |
| `eula` | Лицензия, которую пользователь принимает сам: `url` — текст, `file` — файл согласия, `line` — строка согласия. |
| `files[]` | Файлы в папке сервера, без которых его не запустить. Перед стартом проверяется, что они на месте. |
| `settings[]` | Настройки для пользователя: `id`, `label`, `type` (`text`, `number` — целое, `bool`), `default` — строкой, для чисел `min`, `max`. |
| `ports[]` | `id`, `protocol` (`tcp`/`udp`), `default`, `expose`. С `expose: true` порт уходит в комнату. Хотя бы один такой нужен. |
| `config[]` | Конфиги, где перед каждым запуском выставляются значения: `file`, `format`, `set`; `template` — файл в папке сервера, с которого начать, если конфига ещё нет. `format: "properties"` — ключ=значение (server.properties). `format: "ini"` — INI с секциями (Unreal Engine): нужна `section` (без скобок); со `struct` (например `OptionSettings`) `set` — поля структуры в скобках: они меняются, остальные поля остаются, как их выставил хост. Строку в структуре пишите в кавычках: `"\"{setting:name}\""`. |
| `launch` | `exe`, `args[]` (каждый элемент — один аргумент, пробелы внутри не делят его), `workDir`. Нет — сервер с инструкцией. |
| `log` | `file` — если сервер пишет лог в файл, а не в вывод (Unity-серверы, Rust). |
| `ready` | Когда сервер готов: `log` (регулярное выражение для строки лога) или `port` (id порта, который начинает слушать). `timeoutSeconds` — сколько ждать, по умолчанию 600. |
| `console` | `type`: `stdio` (команды в стандартный ввод), `rcon` (Source RCON по TCP), `webrcon` (WebRCON, Rust), `terminal` (у сервера своя скрытая консоль: команды — нажатиями клавиш, лог — с её экрана; для серверов, которые не читают перенаправленный ввод, как Terraria; только Windows). Для RCON — `port` и `password`. |
| `stop` | `command` — команда, после которой сервер сохраняет мир и закрывается, или `signal: "ctrlC"` — Ctrl+C в консоль сервера (для серверов, которые команд не принимают, как Valheim; только с console `terminal`); `save` — команда сохранения перед `command` (Palworld по `Shutdown` закрывается без сохранения: `"save": "Save"`); `timeoutSeconds` — сколько ждать, потом процесс завершается принудительно. |
| `join` | Как друзьям зайти: `consoleKey` или `menuPath[]`, `template` с `{address}`. |
| `guide` | Тексты для людей: `hint` — строка на карточке игры; `startSteps[]` — как хосту запустить сервер, если приложение его не нашло; `stoppedTips[]` — что делать, если сервер перестал отвечать; `helpUrl` (https) и `helpLabel` — ссылка на помощь. До 8 пунктов в списке, до 300 символов в тексте. |

Неизвестное поле — ошибка: опечатка вроде `sha265` не пропустит проверку хэша молча.

## Сервер с инструкцией

Без `launch` не нужны и не допускаются `install`, `requirements`, `eula`, `files`, `settings`, `config`, `log` и `stop`.
Остаются порты, `join` и `guide`:

```json
{
  "$schema": "https://raw.githubusercontent.com/kreker0001/ConnectTogether-Addons/main/schema/addon.schema.json",
  "format": 1,
  "id": "factorio",
  "name": "Factorio",
  "subtitle": "Игра по сети из самой игры",
  "icon": "gamepad",
  "version": "1.0.0",
  "author": "Команда ConnectTogether",
  "ports": [ { "id": "game", "protocol": "udp", "default": 34197, "expose": true } ],
  "join": { "menuPath": [ "Сетевая игра", "Подключиться по адресу" ] },
  "guide": {
    "hint": "Хост запускает игру из меню «Сетевая игра»",
    "startSteps": [
      "Запустите Factorio: «Сетевая игра» → «Создать игру» и загрузите или создайте карту.",
      "Порт оставьте 34197.",
      "Вернитесь сюда и нажмите «Проверить снова»."
    ],
    "stoppedTips": [
      "Проверьте, не вышли ли вы из игры в главное меню.",
      "Запустите игру по сети снова — комната и код останутся прежними.",
      "Нажмите «Проверить снова»."
    ],
    "helpUrl": "https://wiki.factorio.com/Multiplayer",
    "helpLabel": "Как играть в Factorio по сети"
  }
}
```

## Установка: только два источника

- `{"type": "http", "url": "https://…", "sha256": "…"}` (или `sha1`, если источник публикует только его, как Mojang).
  Файл скачивается, сверяется хэш, и только потом попадает в папку. Если хэш не совпал, установка отменяется.
  - `extract: true` — распаковать zip; `stripRoot: true` — без единственной папки верхнего уровня.
  - `file` — имя файла (без распаковки).
  - `shared: true` — в общую папку: одинаковый архив (по хэшу) ставится один раз на все дополнения. Так ставится Java.
- `{"type": "steamcmd", "appId": 258550}` — выделенный сервер из Steam, анонимно. SteamCMD приложение скачивает само
  с адреса Valve.

Хэш файла: `Get-FileHash server.zip` в PowerShell (SHA-256 по умолчанию) или `sha256sum server.zip` в Linux.
Ссылка должна вести на конкретную версию: версия сервера в манифесте зафиксирована, обновление — новая версия
дополнения с новой ссылкой и хэшем. Шаг с прежним хэшем повторно не качается. Шаг steamcmd выполняется при каждой
установке: SteamCMD сам докачает обновление.

ConnectTogether не раздаёт файлы серверов: только официальные источники.

## Подстановки

Работают в `launch.exe`, `launch.args`, `launch.workDir`, значениях `config[].set` и `console.password`.

| Подстановка | Значение |
|---|---|
| `{port:game}` | Номер порта `game` у этого сервера (пользователь может его поменять) |
| `{setting:name}` | Значение настройки |
| `{secret:rcon}` | Пароль, который приложение придумывает само при первом запуске и хранит у пользователя |
| `{install:java}` | Папка шага установки `java` |
| `{dir}` | Папка сервера |

Ссылка на несуществующий порт, настройку или шаг — ошибка проверки.

## Безопасность

Дополнение может прислать кто угодно, а оно скачивает и запускает программы. Поэтому:

- скачивать можно только по https с хэшем или через SteamCMD по номеру приложения;
- `launch.exe` запускается только из папки сервера или папки шага установки, а не, например, `cmd.exe`;
- пути в `files`, `config`, `log`, `eula` не выходят за папку сервера (`..` и абсолютные пути запрещены);
- порт консоли нельзя открыть друзьям (`expose`);
- согласие с лицензией (`eula`) записывает только кнопка пользователя, а не приложение само;
- дополнение попадает в приложение только после «Добавить» в окне, где видно, что оно скачает, что запустит и какие
  порты откроет; встроенные игры своим дополнением не заменить.

## Как проверить

1. **addon-check** — те же правила, что в приложении, и правила этого репозитория (папка совпадает с `id`, `id` не
   занят). Скачайте `addon-check-win-x64.exe` или `addon-check-linux-x64` из
   [релизов](https://github.com/kreker0001/ConnectTogether-Addons/releases):

   ```
   addon-check-win-x64.exe addons\my-game\addon.json
   addon-check-win-x64.exe --reserved minecraft,rust,minecraft-bedrock,valheim,7-days-to-die,project-zomboid,palworld,terraria,custom addons
   ```

   Все ошибки выводятся сразу, с полем и причиной.
2. **В приложении** — «Добавить из файла», затем экран дополнения: установка, запуск, лог. Исправили файл — добавьте
   снова, новая версия заменит прежнюю.
3. **С другом** — откройте комнату и проверьте, что он заходит по адресу из неё и подсказка `join` верная.

## Пока не умеет

Моды и модпаки, бэкапы, вайпы и расписание. Не останавливает сервер, если приложение закрылось аварийно: сервер
продолжит работать, пока его не закрыть.
